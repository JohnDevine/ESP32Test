Detailed Description

Wi-Fi Access Point scanner for the ESP32.

This application initializes the ESP-IDF Wi-Fi stack in station mode, performs a blocking scan for nearby access points, and logs information about every AP found (SSID, RSSI, authentication mode, cipher suites, and channel).

The scan can optionally be limited to channels 1, 6, and 11 by defining CONFIG_EXAMPLE_USE_SCAN_CHANNEL_BITMAP. The maximum number of results stored is controlled by CONFIG_EXAMPLE_SCAN_LIST_SIZE (defaults to 10).

Note
This example is based on the ESP-IDF Wi-Fi scan example and is released into the Public Domain (or CC0 licensed, at your option).
